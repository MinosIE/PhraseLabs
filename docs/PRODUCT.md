# 产品与内容设计

## 用户旅程

打开首页 → 看到定位、今日训练入口与今日进度 → 直接开练，或按题型/场景进细分 → 看提示并键盘输入 → 即时判定与例句反馈 → 继续下一题 → 在统计页查看掌握情况。全程不需要鼠标，也不需要登录。

## 首页结构

首页承担三件事：说清这是什么站、给出马上能开练的入口、再引导到细分内容。

| 区块 | 内容 | 说明 |
| --- | --- | --- |
| 首屏 | 一句话定位 + 今日训练（含剩余题数）+ 5 条快练 + 词库链接 | 有未完成草稿时次按钮变为「继续上一轮」。上方叠加真实短语视差层（`aria-hidden`，不参与索引与判定），底部短语带随滚动横移；装饰语料取自 `phrases`，内容与入口不变 |
| 今日卡 | 今日进度、连续天数、已掌握、累计作答、到期复习 | 有待复习时直接开出「到期复习」队列：只算学过的到期条，按到期先后取，最多每日目标题量 |
| 站点数据条 | 789 条 / 11 类 / 4 种题型 / 0 次注册 | 用数字说明站点性质：内容规模、题型数、无需账号 |
| 今日一句 | 每天一条短语，可直接练或听 | 见下表 |
| 按题型开练 | 四种题型卡 | 点选即开练，并把该题型记为默认题型 |
| 为什么是「短语 + 键盘」 | 四条特色 | 键盘流不碰鼠标、训练单位是完整短语、错题当轮回炉 + 遗忘曲线排期、进度只存本地可导出备份 |
| 产品演示区 | 用 `a little bit` 的真实中文、英文、例句展示「提示 → 输入 → 判定 → 下次见面」 | 深色舞台 + 浅色产品卡，是本页宣传亮点；数字与文案取自 `phrases`，新增 `demoPhrase` 派生值，不含新交互 |
| 看、敲、再见 | 三步循环说明（看提示 / 键盘输入 / 隔天复习） | 宣传叙事区块，解释训练闭环；不含新交互 |
| 遗忘曲线专题 | 衰减示意图（复习日圆点 + 90% 虚线）+ 4 个数字（90% / ×1.9 / 15 天 / ×0.4） | 把记忆模型作为独立卖点：数字直接引用 `srs.ts` 的 `TARGET_RETENTION`/`GROWTH`/`MASTERED_STABILITY`/`DECAY`，改算法时文案不会脱节；窄屏变单列 |
| 按场景找短语 | 11 个紧凑分类入口 + 条数 | 四列小网格，保留全部分类页内链；此前是两列大卡片，页面过长 |
| 结尾行动区 | 复用首屏同一组训练按钮 | 首屏 CTA 的收口，动作与文案一致，不新增入口 |

## 轻量入口

为了让人「先体验一句再决定要不要练」，首页与分类页各有一个不需要配置的入口：

| 入口 | 位置 | 行为 |
| --- | --- | --- |
| 今日一句 | 首页首屏之下 | 按本地日期做 FNV-1a 哈希，从全库挑一条；同一天刷新不变，跨天自动换。显示英文、中文、双语例句，可直接「练这一条」（本轮只含这 1 条）或「听一遍」 |
| 5 条快练 | 每个分类页标题右侧与页面底部 | 取该分类前 5 条组成本轮队列，约 30 秒完成；不写设置、不改长期分类 |
| 练这一类 | 分类页底部 | 按该分类生成普通队列，受每日目标截断 |

分类页除词条列表外还有专属内容：一段介绍（这类表达是什么、难点在哪）、三条练习建议、一句典型场景、三条 FAQ。介绍与 FAQ 同时写进该页的 `CollectionPage` 与 `FAQPage` 结构化数据。

## 交互反馈

| 操作 | 快捷键 | 效果 |
| --- | --- | --- |
| 输入答案 | 单一输入框 | 中英文共用一个输入框；输入期间不做实时判定、不上色、不自动跳格，只在提交后给结果 |
| 提交 / 下一题 | `Enter` | 未判定时提交，判定后进入下一题 |
| 跳过 | `Esc` | 不计入作答，但会中断连对 |
| 看提示 | `⌥H` | 英文给出各段首字母轮廓与段数；中文给出首字与字数 |
| 收藏 | `⌥F` | 收藏当前短语，可在词库筛选；结果弹框打开时同样可用 |
| 朗读 | `⌥R` / `Ctrl+P` | 手动朗读当前英文短语；答题前仅在「英 → 中」可用，弹框打开后随时可用；自动优选自然音色，设置中可手动指定 |

空答案不会提交：输入框只抖动并提示「先写下答案再提交，空答案不判分」（提示保留到开始输入），不进入判定链路，因此误按 `Enter` 不会降盒、不会计入错误、不会排入复习。判定中的 150ms 内跳过按钮禁用，避免本次作答被静默丢弃。结果弹框里的正确答案旁有朗读按钮，答错时不必先关掉弹框才能听读音；弹框打开时背景页面为 `inert`，焦点与读屏都留在弹框内，点击遮罩不会误跳下一题。

### 判定后的情绪反馈

反馈区不只显示“对/错”，而是按情境给出回应：

- **答对**：大字标题随连对数升级（拿下 → 稳稳的 → 手感来了 → 势不可挡），配 GSAP 缩放图标和庆祝粒子；3 连对起显示里程碑徽章；同时告知熟练度升级和下次复习时间。
- **接近**：说明只差几个字符，给出正确答案和例句，避免单纯判错带来的挫败。
- **答错**：用“答错不是失败，是大脑在标记重点”一类表述承接情绪，并结合该题历史错误次数给不同鼓励；明确告知已排入复习以及何时再见。
- **目标达成**：当次作答让今日量跨过目标线时，反馈区显示“今日目标达成，收工值得庆祝”。

每答一题都会弹出结果弹框，先用「回答正确 / 接近答案 / 回答错误」明确标记结果，再给出大标题、正确答案、例句和鼓励文案；弹框顶部用颜色区分结果，焦点自动落在「下一题」按钮，`Enter` / `Esc` 均可关闭。同时进度条下方会留下一个 `✓` / `✗` 小标记，当前题顶部同步显示「刚刚答对 / 非常接近 / 刚刚答错」，确保每道题都有可见的对错提醒。反馈同时用颜色、图标和文字表达，不依赖单一颜色；答错时卡片轻微抖动，庆祝动画在 `prefers-reduced-motion` 下自动关闭。答错或接近时，弹框在正确答案下方用虚线框并排列出「你的答案」，接近时额外标出「只差 N 个字符」，不用自己回忆刚才写了什么。输入框里有内容时出现圆形 ✕ 一键清空（触屏 36px），只改错字不必逐字删；答错排到队尾的重练题，题头会多一个金色「重练」徽标。借鉴 TypeWords 的错词循环机制：答错或接近的短语会自动追加到本轮队列末尾重练，同时按遗忘曲线安排后续复习；本轮只有 1 条时（今日一句、词库单条）不追加——紧接着重刷同一条几乎不涨记忆，交回曲线排期，结算页直接导向同类与随机两种新范围。本轮最后一题的弹框按钮改叫「看本轮结果 ↵」，不再误导成还有下一题。输入过程中不打断用户，不做实时着色或自动跳格。提示不计入正确率，但会记录使用次数。

## 训练模式

| 模式 | 提示 | 用户输入 | 判定 |
| --- | --- | --- | --- |
| 混合 | 按题序自动切换 | 随题型变化 | 约 70% 中→英、30% 英→中 |
| 中 → 英 | 中文释义 + 中文语境句 | 英文短语 | 英文归一化后精确/编辑距离匹配 |
| 英 → 中 | 英文短语 + 英文例句 | 中文意思 | 命中 `aliases` 任一关键词即算对 |
| 例句填空 | 挖掉短语的英文例句 | 英文短语 | 同中→英 |

填空题会把示例句中首次出现的短语替换为 `______`；若例句中未包含该短语则整句作为提示显示。朗读为手动触发的辅助功能，不影响判定。

朗读入口按能力与场景收敛：设备没有可用英文音色时，学习页、结果弹框、词库的朗读按钮与快捷键整体隐藏，设置页的音色下拉显示「当前设备无可用英文音色」；设备有音色时，答对/答错后的弹框与词库都可直接朗读。答题**前**只有「英 → 中」提供朗读——中 → 英与例句填空的答案就是那句英文，提前朗读等于免费提示，因此答题前不提供入口（弹框打开后不再限制）。点击朗读时按钮立即进入加载态，并在声音真正开始播放的瞬间恢复，不等待整句读完。

词库的搜索（含中文别名）支持一键清空：输入框右侧的 ✕ 只清搜索词、保留分类/难度/状态筛选，`Esc` 效果相同，清空后焦点留在输入框；结果条数带 `aria-live` 播报。工具栏不再放页面级「清空筛选」（分类 chip、状态 tab、难度与排序都有「全部」选项，重复），只有搜不到结果时在空状态里给一个「清空筛选」链接兼底。搜索、分类、难度、状态筛选结果可以直接变成一轮训练（「练这 N 条」），不按每日目标截断；首页的分类入口、统计页的「最该复习的 5 条」同样只影响本轮，不改写设置里的长期分类。学习页顶部的进度以本轮计划题数为分母，答错追加的重练单独显示为「待重练 N 题」，因此进度条不会倒退；本轮草稿存在 sessionStorage，刷新页面可以接着练，跨天自动作废。

## 判定规则

1. 英文归一化：转小写、统一弯引号、把中文标点和非字母数字字符视作空格、连字符等价为空格、合并多余空白。
2. 中文归一化：移除标点、空白和省略号后做关键词包含判断；关键词至少 2 个字，避免误命中。
3. 严格度：
   - `strict`：仅完全匹配算对；
   - `normal`：编辑距离 1 以内显示“很接近”，但不算对；
   - `lenient`：编辑距离 1 以内算对，2 以内显示“很接近”。
4. `near` 与 `wrong` 都按“未答对”进入复习算法，且这一判定不可被推翻：答错了就是答错了，正确率、连对与错误次数都不会因为用户声明而改写。结果弹框提供「这条我会了」：只把该短语的稳定度抬到已掌握（`>= 15` 天）并推后下次复习，同时撤掉本轮队尾的那次重练；按钮点击后变为「已标记为掌握，不计入正确率」。
5. 空答案不提交：输入框抖动提示并保留焦点，不计入作答；中文输入法组合中的 Enter 不会误提交。

## 记忆算法

按艾宾浩斯式遗忘曲线排期，每条短语只记一个「记忆稳定度」`stability`（天）：

- 回忆概率 `R(Δt) = 0.9 ^ (Δt / stability)`，`Δt` 是距上次复习的天数；`R` 跌回 0.9 即到期，因此 `nextReview = lastReviewed + stability 天`。
- 新词按 1 天基准起算。答对把稳定度乘 1.9；如果拖到逾期 1.5 倍以上才复习（记忆已明显衰减），只乘 1.35；历史错误率超过 40% 的词再乘 0.85，避免难词被推得太远。答错把稳定度缩到 40%，下限 0.5 天（半天后再见），上限 180 天。
- 稳定度 ≥ 15 天视为已掌握（统计页「已掌握」口子）。
- 生成队列时：先取到期项，按当前保留率从低到高排序（快忘的先复习，新词的保留率记 0，排最前）；再随机补充未到期项，总数不超过每日目标。
- 「这条我会了」把稳定度抬到 15 天并推后排期，不改对错计数。
- 兼容旧数据：读取与导入时，旧版 6 格 Leitner 的盒子按 1/1/2/4/7/15 天换算成稳定度，其他字段不动。
- 统计口径：作答数含答错；正确率 = 正确数 / 作答数；连续天数按本地日期计算，今天未学则从昨天起算；周环比为近 7 天作答量相对前 7 天的变化，上周为 0 时显示「—」。
- 「待重练」是答错或接近后追加到队尾的重复练习，不计入计划题数、不改变进度分母；跳过不追加。
- 已经掌握但被打回（连续答错）的短语会重新回到队列，稳定度也会随答错缩水，不会因为曾掌握而永久免修。

## 本轮结算与最高连对

答完最后一题（或恢复的草稿已经结完）后不再直接跳回首页，而是停在结算页：

| 指标 | 口径 |
| --- | --- |
| 作答题数 | 本轮实际作答数，含答错，不含跳过 |
| 正确率 | 正确数 / 作答题数，四舍五入到整数 |
| 本轮最高连对 | 本轮内最长的一次连续答对；刷新历史记录时旁边显示「新纪录」徽标 |
| 明天到期 | 已学短语中，在明天结束前会到期的条数 |

页脚补三笔小账：本轮新掌握（结算时的已掌握数 − 本轮开始时的已掌握数）、提示次数、历史最高连对及其破纪录日期（本地日期）。标题下的一句话按正确率分档：90% 以上「明天那几条过一遍就够」、70% 以上「没答对的那几条排到了下一轮前面」、更低则说明错题已被标记、下一轮会优先再问，0 作答时提示随时可重新开始。

底部出口按轮次类型分流：多题轮次仍是「再来一轮」（沿用本轮范围）、「看统计」、「回到首页」；单条轮次（首页「今日一句」、词库只练 1 条）不再提供原地重复，主按钮换成「再练 5 条同类」（同分类随机 5 条，排除刚练的那条）、次按钮「随机 5 条」（全库随机 5 条），并在按钮下说明刚练的是哪条、属于哪类。结算页出现时焦点落在主按钮上，键盘用户不会掉出页面。

历史最高连对只增不减，存为 `{ combo, day }` 并独立落在 `phraselabs:v1:best-combo`：逐题答对时就地比较，结算前（含刷新恢复的草稿）再补记一次，所以不会漏记本轮；它随 JSON 备份导出导入，旧备份缺这个字段时归零。「新纪录」徽标只是本轮内的状态，不落盘，刷新后同一次结算不再显示。

## 内容体系

现有 789 条，分 11 类：日常口语 148、习语俗语 166、动词短语 77、一词多义 84、学术写作 48、职场沟通 46，商务邮件 / 介词搭配 / 旅行出行 / 情绪表达 / 连接过渡各 44。除叠词习语用连字符书写（如 `fifty-fifty`）外，全部以含空格的短语为单位，不收录孤立单词；全库英文短语唯一，已清理跨分类重复条目。内容扩充以常见、简单、日常高频表达为优先，日常口语类收录大量问候、起居、饮食、家务与简短回应短语，多为难度 1；近期补充了 `it depends`、`on my way`、`my treat`、`keep in touch` 等口语高频表达，以及 `at the end of the day`、`in a nutshell`、`hands down` 等常考习语和 `turn out`、`take over`、`make a difference` 等短语动词；最近一轮新增 26 条影视/美剧高频台词（如 `you can say that again`、`what’s the catch`、`hold your horses`、`none of your business`）、14 条电影里常见的习语（如 `over my dead body`、`easier said than done`、`what’s done is done`）和 24 条叠词习语（同一个词重复，如 `so-so`、`fifty-fifty`、`chit-chat`、`now now`、`there there`），叠词用连字符或空格书写，判定时连字符会归一化为空格。另补 62 条「同词重复/成对搭配」习语：16 条 `X is X` 句式（如 `life is life`、`business is business`、`rules are rules`、`money is money`）、18 条重复结构（如 `again and again`、`little by little`、`step by step`、`face to face`、`never say never`）与 28 条高频成对搭配（如 `now and then`、`ups and downs`、`safe and sound`、`first come, first served`、`through thick and thin`），整体表达“就是这样/公事公办/逐步地/反复地”这类固定态度与方式。「一词多义」用成对短语展示同一个词在不同搭配里的不同意思，例如“book a table（预订餐桌）”与“read a book（读书）”；近期又补 12 组共 24 条高频成对短语（如 `charge the phone` / `free of charge`、`sign a contract` / `a road sign`、`watch a match` / `match the color`），每组共用同一个词的不同义项。难度 1–5 级，每条包含英文、中文、中文别名、分类、标签、难度、双语例句和可选用法提示。

首页、词库、设置页的分类入口都展示各类条数。后续考虑社区 PR 供稿与内容校验脚本。
